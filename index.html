    Pour une voix plus humaine, gratuite : sur iPhone, Réglages › Accessibilité › Contenu énoncé › Voix › Français, puis téléchargez une voix « améliorée » ou « premium ». Sur Android, Paramètres › Synthèse vocale › Google, voix française haute qualité.

    Sonnerie

    iPhone : sonner même verrouillé

    1. Horloge › Alarmes › + : choisis l’heure, nomme l’alarme « Angélus ». Dans Sonnerie, « Choisir un morceau » permet de prendre un chant de ta bibliothèque Musique.
    2. Raccourcis › Automatisation › + › Alarme › « Est arrêtée » › alarme Angélus › Exécuter immédiatement.
    3. Ajoute l’action Ouvrir les URL avec :
    4. Le matin, l’alarme sonne même téléphone verrouillé. Arrête-la et déverrouille : Angélus s’ouvre, touche « Commencer ».

    Installer sur le téléphone

    1. iPhone : ouvrez cette page dans Safari, touchez Partager, puis « Sur l’écran d’accueil ».
    2. Android : dans Chrome, menu ⋮ puis « Installer l’application ».

    Pour que le réveil sonne

    Une app web ne peut pas réveiller un téléphone verrouillé. Le soir, ouvrez Angélus et touchez Mode chevet : l’écran reste allumé, presque noir, et le chant du lendemain est déjà téléchargé. Branchez le téléphone et laissez le volume média monté.
